# Soul.Table para Windows

Este repositório distribui os pacotes de atualização do Soul.Table para Windows GM e Player.

Baixe a edição desejada na [versão mais recente](https://github.com/luizram17/soul-table-updates/releases/latest).

- **GM:** hospeda e gerencia a campanha.
- **Player:** conecta os jogadores à sessão do GM.

Na primeira instalação, extraia o ZIP para uma pasta gravável e abra o executável da edição escolhida. Mantenha todos os arquivos extraídos juntos.

A partir desta versão, use **Configurações > Atualizações > Verificar agora**. O aplicativo baixa o pacote de sua edição, verifica a assinatura e a integridade e pede sua confirmação para instalar e reiniciar. Fichas e campanhas ficam preservadas.

Os builds anteriores sem o download integrado precisam dessa primeira instalação manual. Android não faz parte desta entrega.

Os manifestos e os pacotes são assinados com uma chave de atualização do projeto. Os arquivos publicados de uma versão não são substituídos; cada atualização recebe um número de versão novo.
